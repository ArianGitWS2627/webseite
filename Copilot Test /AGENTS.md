# Projektregeln

- Aktualisiere `README.md` bei jeder Änderung an einem Projektbestandteil im selben Arbeitsauftrag. Das gilt insbesondere für `index.html`, `styles.css`, `app.js`, `Datensatz.csv` und die Projektkonfiguration.
- Beschreibe in der README die tatsächlich geänderten Funktionen, Darstellung, Daten und Bedienung. Halte Links, Kennzahlen, Monatsübersichten und Transaktionstabellen mit der Website und `Datensatz.csv` synchron.
- Übernimm Änderungen am Datensatz exakt aus der Quelle; erfinde keine Informationen und rechne unterschiedliche Währungen nicht ohne ausdrücklich definierte Wechselkurse zusammen.
- Prüfe vor Abschluss, ob README, Website und Datensatz zueinander passen. Passe die README gezielt an, ohne unveränderte Inhalte unnötig umzuschreiben.
